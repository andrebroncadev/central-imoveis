# Central Imóveis

Sistema pessoal para organizar imóveis e facilitar a pesquisa durante o atendimento de leads.

## Primeira versão

- PHP
- SQLite
- CRUD de imóveis
- pesquisa simples
- organização de fotos

> Repositório privado. Não coloque dados reais de clientes, proprietários ou documentos no GitHub.

## Rodar localmente

```bash
php -S localhost:8000
```

Depois acesse `http://localhost:8000`.

O banco SQLite será criado localmente quando a aplicação for executada.
